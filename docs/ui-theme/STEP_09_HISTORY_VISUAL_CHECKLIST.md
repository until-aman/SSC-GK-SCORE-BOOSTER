- Header/top bar is white/light and readable.
- Badge is teal/soft teal.
- Page background is soft teal-white.
- Review / Revise / Re-attempt / Track strip is light and readable.
- Menu/list card is white with soft border and shadow.
- Quiz History item is visible and tappable.
- Saved Questions landing item is visible and tappable.
- Repeated Mistakes landing item is visible and tappable.
- Coins History landing item is visible and tappable.
- Streak History landing item is visible and tappable.

- Icons sit in soft color chips.
- Chevrons/arrows are readable.
- Guest preview and lock card are light.
- Sign-in modal is light and readable.
- Bottom nav spacing is safe.
- No white text appears on white cards.

- Page background is soft teal-white.

- Active selector uses teal.

- Score is readable.

- Practice Mistakes CTA is orange and rounded.

- Show More / Show Less is readable.
- Loading state is readable.

- Error/retry state is readable.
- Date range modal is light.
